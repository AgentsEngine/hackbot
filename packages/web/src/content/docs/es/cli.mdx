La CLI de Hackbot de forma predeterminada inicia el [TUI](/docs/tui) cuando se ejecuta sin ningún argumento.

```bash
hackbot
```

Pero también acepta comandos como se documenta en esta página. Esto le permite interactuar con Hackbot mediante programación.

```bash
hackbot run "Explain how closures work in JavaScript"
```

---

### tui

Inicie la interfaz de usuario del terminal Hackbot.

```bash
hackbot [project]
```

#### Opciones

| Opción                                   | Corta | Descripción                                                           |
| ---------------------------------------- | ----- | --------------------------------------------------------------------- |
| <nobr><code>{"--continue"}</code></nobr> | `-c`  | Continuar la última sesión                                            |
| <nobr><code>{"--session"}</code></nobr>  | `-s`  | ID de sesión para continuar                                           |
| <nobr><code>{"--fork"}</code></nobr>     |       | Bifurcar la sesión al continuar (usar con `--continue` o `--session`) |
| <nobr><code>{"--prompt"}</code></nobr>   |       | Aviso de uso                                                          |
| <nobr><code>{"--model"}</code></nobr>    | `-m`  | Modelo a utilizar en forma de proveedor/modelo                        |
| <nobr><code>{"--agent"}</code></nobr>    |       | Agente a utilizar                                                     |
| <nobr><code>{"--port"}</code></nobr>     |       | Puerto para escuchar                                                  |
| <nobr><code>{"--hostname"}</code></nobr> |       | Nombre de host para escuchar                                          |

## Comandos

La CLI de Hackbot también tiene los siguientes comandos.

---

### agent

Administrar agentes para Hackbot.

```bash
hackbot agent [command]
```

---

### attach

Conecte una terminal a un servidor backend Hackbot que ya se esté ejecutando y iniciado mediante los comandos `serve` o `web`.

```bash
hackbot attach [url]
```

Esto permite usar TUI con un backend remoto Hackbot. Por ejemplo:

```bash
# Start the backend server for web/mobile access
hackbot web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
hackbot attach http://10.20.30.40:4096
```

#### Opciones

| Opción                                   | Corta | Descripción                                                                             |
| ---------------------------------------- | ----- | --------------------------------------------------------------------------------------- |
| <nobr><code>{"--dir"}</code></nobr>      |       | Directorio de trabajo para iniciar TUI en                                               |
| <nobr><code>{"--continue"}</code></nobr> | `-c`  | Continuar la última sesión                                                              |
| <nobr><code>{"--session"}</code></nobr>  | `-s`  | ID de sesión para continuar                                                             |
| <nobr><code>{"--fork"}</code></nobr>     |       | Bifurcar la sesión al continuar (usar con `--continue` o `--session`)                   |
| <nobr><code>{"--password"}</code></nobr> | `-p`  | Contraseña de autenticación básica (predeterminada: `HACKBOT_SERVER_PASSWORD`)          |
| <nobr><code>{"--username"}</code></nobr> | `-u`  | Usuario de autenticación básica (predeterminado: `HACKBOT_SERVER_USERNAME` u `hackbot`) |

#### create

```bash
hackbot agent create
```

Este comando lo guiará en la creación de un nuevo agente con un mensaje del sistema personalizado y una configuración de herramientas.

#### list

Enumere todos los agentes disponibles.

```bash
hackbot agent list
```

### auth

Comando para administrar credenciales e iniciar sesión para proveedores.

```bash
hackbot auth [command]
```

---

#### login

Hackbot funciona con la lista de proveedores en [Models.dev](https://models.dev), por lo que puede usar `hackbot auth login` para configurar las claves API para cualquier proveedor que desee utilizar. Esto se almacena en `~/.local/share/hackbot/auth.json`.

```bash
hackbot auth login
```

Cuando se inicia Hackbot, carga los proveedores desde el archivo de credenciales. Y si hay claves definidas en sus entornos o un archivo `.env` en su proyecto.

---

#### list

Enumera todos los proveedores autenticados tal como están almacenados en el archivo de credenciales.

```bash
hackbot auth list
```

O la versión corta.

```bash
hackbot auth ls
```

---

#### logout

Cierra tu sesión de un proveedor eliminándolo del archivo de credenciales.

```bash
hackbot auth logout
```

### github

Administre el agente GitHub para la automatización del repositorio.

```bash
hackbot github [command]
```

---

#### install

Instale el agente GitHub en su repositorio.

```bash
hackbot github install
```

Esto configura el flujo de trabajo de acciones GitHub necesario y lo guía a través del proceso de configuración. [Más información](/docs/github).

---

Ejecute el agente GitHub. Esto se usa normalmente en acciones GitHub.

```bash
hackbot github run
```

##### Opciones

| Opción                                | Descripción                                    |
| ------------------------------------- | ---------------------------------------------- |
| <nobr><code>{"--event"}</code></nobr> | GitHub evento simulado para ejecutar el agente |
| <nobr><code>{"--token"}</code></nobr> | GitHub token de acceso personal                |

### mcp

Administrar servidores de protocolo de contexto modelo.

```bash
hackbot mcp [command]
```

---

#### add

Agregue un servidor MCP a su configuración.

```bash
hackbot mcp add
```

Este comando lo guiará para agregar un servidor MCP local o remoto.

---

#### list

Enumere todos los servidores MCP configurados y su estado de conexión.

```bash
hackbot mcp list
```

O utilice la versión corta.

```bash
hackbot mcp ls
```

---

#### auth

Autentíquese con un servidor MCP habilitado para OAuth.

```bash
hackbot mcp auth [name]
```

Si no proporciona un nombre de servidor, se le pedirá que seleccione entre los servidores compatibles con OAuth disponibles.

También puede enumerar los servidores compatibles con OAuth y su estado de autenticación.

```bash
hackbot mcp auth list
```

O utilice la versión corta.

```bash
hackbot mcp auth ls
```

---

#### logout

Elimine las credenciales OAuth para un servidor MCP.

```bash
hackbot mcp logout [name]
```

---

#### debug

Depurar problemas de conexión OAuth para un servidor MCP.

```bash
hackbot mcp debug <name>
```

### models

Enumere todos los modelos disponibles de los proveedores configurados.

```bash
hackbot models [provider]
```

Este comando muestra todos los modelos disponibles en sus proveedores configurados en el formato `provider/model`.

Esto es útil para determinar el nombre exacto del modelo que se usará en [su configuración](/docs/config/).

Opcionalmente, puede pasar un ID de proveedor para filtrar modelos por ese proveedor.

```bash
hackbot models anthropic
```

#### Opciones

| Opción                                  | Descripción                                                                 |
| --------------------------------------- | --------------------------------------------------------------------------- |
| <nobr><code>{"--refresh"}</code></nobr> | Actualizar la caché de modelos desde models.dev                             |
| <nobr><code>{"--verbose"}</code></nobr> | Utilice una salida del modelo más detallada (incluye metadatos como costos) |

Utilice el indicador `--refresh` para actualizar la lista de modelos almacenados en caché. Esto es útil cuando se han agregado nuevos modelos a un proveedor y desea verlos en Hackbot.

```bash
hackbot models --refresh
```

### run

Ejecute hackbot en modo no interactivo pasando un mensaje directamente.

```bash
hackbot run [message..]
```

Esto es útil para secuencias de comandos, automatización o cuando desea una respuesta rápida sin iniciar el TUI completo. Por ejemplo.

```bash "hackbot run"
hackbot run Explain the use of context in Go
```

También puede conectarse a una instancia `hackbot serve` en ejecución para evitar tiempos de arranque en frío del servidor MCP en cada ejecución:

```bash
# Start a headless server in one terminal
hackbot serve

# In another terminal, run commands that attach to it
hackbot run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### Opciones

| Opción                                   | Corta | Descripción                                                                             |
| ---------------------------------------- | ----- | --------------------------------------------------------------------------------------- |
| <nobr><code>{"--command"}</code></nobr>  |       | El comando a ejecutar, use mensaje para args                                            |
| <nobr><code>{"--continue"}</code></nobr> | `-c`  | Continuar la última sesión                                                              |
| <nobr><code>{"--session"}</code></nobr>  | `-s`  | ID de sesión para continuar                                                             |
| <nobr><code>{"--fork"}</code></nobr>     |       | Bifurcar la sesión al continuar (usar con `--continue` o `--session`)                   |
| <nobr><code>{"--share"}</code></nobr>    |       | Comparte la sesión                                                                      |
| <nobr><code>{"--model"}</code></nobr>    | `-m`  | Modelo a utilizar en forma de proveedor/modelo                                          |
| <nobr><code>{"--agent"}</code></nobr>    |       | Agente a utilizar                                                                       |
| <nobr><code>{"--file"}</code></nobr>     | `-f`  | Archivo(s) para adjuntar al mensaje                                                     |
| <nobr><code>{"--format"}</code></nobr>   |       | Formato: predeterminado (formateado) o json (eventos JSON sin formato)                  |
| <nobr><code>{"--title"}</code></nobr>    |       | Título de la sesión (utiliza un mensaje truncado si no se proporciona ningún valor)     |
| <nobr><code>{"--attach"}</code></nobr>   |       | Adjuntar a un servidor hackbot en ejecución (por ejemplo, http://localhost:4096)        |
| <nobr><code>{"--password"}</code></nobr> | `-p`  | Contraseña de autenticación básica (predeterminada: `HACKBOT_SERVER_PASSWORD`)          |
| <nobr><code>{"--username"}</code></nobr> | `-u`  | Usuario de autenticación básica (predeterminado: `HACKBOT_SERVER_USERNAME` u `hackbot`) |
| <nobr><code>{"--dir"}</code></nobr>      |       | Directorio de ejecución, o ruta en el servidor remoto al adjuntar                       |
| <nobr><code>{"--variant"}</code></nobr>  |       | Variante del modelo (esfuerzo de razonamiento específico del proveedor)                 |
| <nobr><code>{"--thinking"}</code></nobr> |       | Mostrar bloques de pensamiento                                                          |
| <nobr><code>{"--port"}</code></nobr>     |       | Puerto para el servidor local (el puerto predeterminado es aleatorio)                   |

### serve

Inicie un servidor Hackbot sin cabeza para acceso API. Consulte los [documentos del servidor](/docs/server) para conocer la interfaz HTTP completa.

```bash
hackbot serve
```

Esto inicia un servidor HTTP que proporciona acceso API a la funcionalidad hackbot sin la interfaz TUI. Configure `HACKBOT_SERVER_PASSWORD` para habilitar la autenticación básica HTTP (el nombre de usuario predeterminado es `hackbot`).

#### Opciones

| Opción                                   | Descripción                                          |
| ---------------------------------------- | ---------------------------------------------------- |
| <nobr><code>{"--port"}</code></nobr>     | Puerto para escuchar                                 |
| <nobr><code>{"--hostname"}</code></nobr> | Nombre de host para escuchar                         |
| <nobr><code>{"--mdns"}</code></nobr>     | Habilitar el descubrimiento de mDNS                  |
| <nobr><code>{"--cors"}</code></nobr>     | Orígenes de navegador adicionales para permitir CORS |

### stats

Muestre el uso de tokens y las estadísticas de costos para sus sesiones Hackbot.

```bash
hackbot stats
```

#### Opciones

| Opción                                  | Descripción                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| <nobr><code>{"--days"}</code></nobr>    | Mostrar estadísticas de los últimos N días (todo el tiempo)                                                              |
| <nobr><code>{"--tools"}</code></nobr>   | Número de herramientas para mostrar (todas)                                                                              |
| <nobr><code>{"--models"}</code></nobr>  | Mostrar el desglose del uso del modelo (oculto de forma predeterminada). Pase un número para mostrar la parte superior N |
| <nobr><code>{"--project"}</code></nobr> | Filtrar por proyecto (todos los proyectos, cadena vacía: proyecto actual)                                                |

### export

Exportar datos de la sesión como JSON.

```bash
hackbot export [sessionID]
```

Si no proporciona una ID de sesión, se le pedirá que seleccione entre las sesiones disponibles.

### import

Importe datos de sesión desde un archivo JSON o una URL compartida Hackbot.

```bash
hackbot import <file>
```

Puede importar desde un archivo local o una URL compartida Hackbot.

```bash
hackbot import session.json
hackbot import https://opncd.ai/s/abc123
```

### uninstall

Desinstale Hackbot y elimine todos los archivos relacionados.

```bash
hackbot uninstall
```

#### Opciones

| Opción                                      | Corta | Descripción                               |
| ------------------------------------------- | ----- | ----------------------------------------- |
| <nobr><code>{"--keep-config"}</code></nobr> | `-c`  | Mantener archivos de configuración        |
| <nobr><code>{"--keep-data"}</code></nobr>   | `-d`  | Conservar datos de sesión e instantáneas  |
| <nobr><code>{"--dry-run"}</code></nobr>     |       | Mostrar lo que se eliminaría sin eliminar |
| <nobr><code>{"--force"}</code></nobr>       | `-f`  | Saltar mensajes de confirmación           |

---

### upgrade

Actualiza hackbot a la última versión o a una versión específica.

```bash
hackbot upgrade [target]
```

Para actualizar a la última versión.

```bash
hackbot upgrade
```

Para actualizar a una versión específica.

```bash
hackbot upgrade v0.1.48
```

#### Opciones

| Opción                                 | Corta | Descripción                                                         |
| -------------------------------------- | ----- | ------------------------------------------------------------------- |
| <nobr><code>{"--method"}</code></nobr> | `-m`  | El método de instalación que se utilizó; curl, npm, pnpm, bun, brew |

## Variables de entorno

Hackbot se puede configurar mediante variables de entorno.

| Variable                             | Type     | Description                                                                    |
| ------------------------------------ | -------- | ------------------------------------------------------------------------------ |
| `HACKBOT_AUTO_SHARE`                 | booleano | Compartir sesiones automáticamente                                             |
| `HACKBOT_GIT_BASH_PATH`              | cadena   | Ruta al ejecutable de Git Bash en Windows                                      |
| `HACKBOT_CONFIG`                     | cadena   | Ruta al archivo de configuración                                               |
| `HACKBOT_CONFIG_DIR`                 | cadena   | Ruta al directorio de configuración                                            |
| `HACKBOT_CONFIG_CONTENT`             | cadena   | Contenido de configuración json en línea                                       |
| `HACKBOT_DISABLE_AUTOUPDATE`         | booleano | Deshabilitar las comprobaciones automáticas de actualizaciones                 |
| `HACKBOT_DISABLE_PRUNE`              | booleano | Deshabilitar la poda de datos antiguos                                         |
| `HACKBOT_DISABLE_TERMINAL_TITLE`     | booleano | Deshabilitar las actualizaciones automáticas de títulos de terminal            |
| `HACKBOT_PERMISSION`                 | cadena   | Configuración de permisos json incorporados                                    |
| `HACKBOT_DISABLE_DEFAULT_PLUGINS`    | booleano | Deshabilitar complementos predeterminados                                      |
| `HACKBOT_DISABLE_LSP_DOWNLOAD`       | booleano | Deshabilitar las descargas automáticas del servidor LSP                        |
| `HACKBOT_ENABLE_EXPERIMENTAL_MODELS` | booleano | Habilitar modelos experimentales                                               |
| `HACKBOT_DISABLE_AUTOCOMPACT`        | booleano | Deshabilitar la compactación automática de contexto                            |
| `HACKBOT_DISABLE_CLAUDE_CODE`        | booleano | Deshabilitar la lectura desde `.claude` (mensaje + habilidades)                |
| `HACKBOT_DISABLE_CLAUDE_CODE_PROMPT` | booleano | Desactivar lectura `~/.claude/CLAUDE.md`                                       |
| `HACKBOT_DISABLE_CLAUDE_CODE_SKILLS` | booleano | Deshabilitar la carga `.claude/skills`                                         |
| `HACKBOT_DISABLE_MODELS_FETCH`       | booleano | Deshabilitar la recuperación de modelos desde fuentes remotas                  |
| `HACKBOT_FAKE_VCS`                   | cadena   | Proveedor de VCS falso para fines de prueba                                    |
| `HACKBOT_CLIENT`                     | cadena   | Identificador de cliente (por defecto `cli`)                                   |
| `HACKBOT_ENABLE_EXA`                 | booleano | Habilitar las herramientas de búsqueda web de Exa                              |
| `HACKBOT_SERVER_PASSWORD`            | cadena   | Habilite la autenticación básica para `serve`/`web`                            |
| `HACKBOT_SERVER_USERNAME`            | cadena   | Anular el nombre de usuario de autenticación básica (predeterminado `hackbot`) |
| `HACKBOT_MODELS_URL`                 | cadena   | URL personalizada para buscar la configuración de modelos                      |
